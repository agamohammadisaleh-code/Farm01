# سرویس تحلیل (FastAPI)

سرویس مستقل برای پیش‌بینی و هشدار. **API اصلی به آن وابسته نیست**؛ اگر خاموش
باشد، NestJS همان محاسبات را با بسته دامنه انجام می‌دهد و پاسخ را با
`source: "local"` برمی‌گرداند.

## اجرا

```bash
cd services/ai
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

مستندات تعاملی: `http://localhost:8000/docs`

## آزمون

```bash
python -m pytest -q
```

## قرارداد API

| مسیر | ورودی | خروجی |
|---|---|---|
| `GET /health` | — | وضعیت و فهرست مدل‌ها |
| `GET /standards/weight?day&breed` | روز و نژاد | وزن استاندارد همان نژاد |
| `GET /standards/breeds` | — | فهرست منحنی‌های نژاد موجود |
| `POST /predict/weight` | وزن‌گیری‌ها، سن و وزن هدف، نژاد | وزن پیش‌بینی‌شده + منحنی کامل + نژاد + ضریب اعتماد |
| `POST /predict/loading-date` | سن، وزن، رشد، قیمت‌ها، نژاد، تعداد زنده، تلفات روزانه | تاریخ بهینه + دلیل + جدول تصمیم روزانه (`breakdown`) |
| `POST /alerts/disease` | سری روزانه (تلفات، دان، آب، دما)، نژاد، آستانه‌های مزرعه | امتیاز ریسک، عوامل، روند هر سیگنال (`trends`)، توصیه |
| `POST /forecast/feed` | مصرف روزهای اخیر، موجودی | مصرف ۷ روز آینده و روزهای باقی‌مانده انبار |
| `GET /assistant/stt/status` | — | آیا موتور تبدیل گفتار آماده است |
| `POST /assistant/transcribe` | صدای base64، زبان | متن + موتور + مدت (یا ۵۰۳ اگر موتوری نصب نیست) |

## نژادها

منحنی رشد چهار نژاد رایج (راس ۳۰۸، کاب ۵۰۰، هابارد، آربور ایکرز) در
`app/breeds.py` است و همان اعدادی را دارد که `packages/domain/src/breeds.ts`.
آزمون `test_breed_curves_match_typescript_package` این هم‌خوانی را تضمین
می‌کند. نژاد ناشناخته با پیش‌فرض راس و یادداشت صریح پاسخ داده می‌شود.

## تاریخ بارگیری

به‌جای «تا وزن هدف»، سود حاشیه‌ای هر روز سنجیده می‌شود: ارزش رشد روزانه منهای
هزینه دان همان روز (ضریب تبدیل حاشیه‌ای منحنی) منهای هزینه فرصت تلفات. خروجی
`breakdown` هر روز را نشان می‌دهد تا توصیه قابل بررسی باشد.

## تبدیل گفتار (اختیاری)

سه مسیر، همه اختیاری: `AI_STT_URL` (سرویس HTTP خارجی)، `faster-whisper` اگر
نصب باشد، یا `vosk` با `AI_VOSK_MODEL`. اگر هیچ‌کدام نباشد، `/assistant/transcribe`
با ۵۰۳ و پیام روشن پاسخ می‌دهد و کلاینت از موتور گفتار دستگاه استفاده می‌کند.
فهم جمله فارسی در بسته دامنه (TypeScript) است، نه این‌جا؛ این سرویس فقط صدا
را به متن تبدیل می‌کند.

## چرا مدل پارامتری و نه یادگیری عمیق؟

با داده یک مزرعه (چند ده وزن‌گیری در هر دوره) شبکه عصبی بیش‌برازش می‌شود و
نتیجه‌اش قابل توضیح نیست. مدل گومپرتز (رشد زیستی استاندارد طیور) با کمترین
مربعات روی نمونه‌ها برازش می‌شود و خروجی همراه دلیل و ضریب اعتماد است؛ مالک
می‌فهمد چرا سیستم عددی را داده است.

## امنیت

اگر `AI_API_KEY` تنظیم شود، همه مسیرهای `/predict` و `/alerts` هدر
`X-AI-Key` را الزام می‌کنند. `AI_CORS_ORIGINS` فهرست مبدأهای مجاز را تعیین
می‌کند (پیش‌فرض `http://localhost:3000`).
