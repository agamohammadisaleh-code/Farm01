# مرغ‌یار — مدیریت هوشمند پرورش مرغ گوشتی

سیستمی یکپارچه برای مدیریت **چرخه کامل پرورش مرغ گوشتی** از جوجه‌ریزی تا فروش؛ با رابط کاربری **فارسی و راست‌به‌چپ**، شفاف‌سازی هزینه‌ها و **مشاور هوشمند** برای تصمیم‌گیری مرغدار.

سامانه از **دو کلاینت** روی یک مدل داده مشترک تشکیل شده است:

| کلاینت | مسیر | کاربرد |
|---|---|---|
| **داشبورد وب** | `/` | تحلیل، گزارش، تنظیمات، مدیریت کامل هزینه و فروش |
| **اپلیکیشن موبایل (PWA)** | `/m` | ثبت سریع آمار در سالن، هشدارها، تصمیم‌گیری روی گوشی، کارکرد آفلاین |

> 📱 راهنمای موبایل: [`docs/MOBILE.md`](docs/MOBILE.md) · 🔍 گزارش بازبینی مهندسی: [`docs/AUDIT.md`](docs/AUDIT.md)

## قابلیت‌ها

### اپلیکیشن موبایل (نصب‌شدنی)
- نصب روی صفحه اصلی اندروید و iOS با آیکون و اجرای مستقل (بدون نوار مرورگر)
- صفحه خانه با KPI مزرعه، هشدارهای بحرانی و موجودی دان
- **ثبت سریع آمار روزانه** با دکمه‌های ±، مقدار پیشنهادی دان/آب و پذیرش ارقام فارسی
- تب‌های دوره: کلی، رشد، هزینه، فروش، تحلیل — همه در قالب انگشتی
- مشاور هوشمند در قالب گفتگوی موبایلی
- پشتیبانی آفلاین برای صفحه‌های بازدیدشده + نوار هشدار قطعی اتصال
- کد QR نصب در صفحه تنظیمات برای انتقال نشانی به گوشی

### مدیریت چرخه پرورش
- ثبت دوره جدید: نام، سالن، نژاد، تاریخ جوجه‌ریزی (تقویم شمسی)، تعداد جوجه، قیمت جوجه، وزن و سن هدف
- محاسبه خودکار سن گله، روزهای باقی‌مانده و پیشرفت دوره
- بستن/بازگشایی دوره و ثبت فروش پله‌ای تا پایان چرخه
- تاریخ‌های کامل شمسی با تقویم داخلی (بدون وابستگی خارجی)

### ثبت روزانه و پایش رشد
- ثبت تلفات، حذف انتخابی، دان و آب مصرفی، دمای سالن، وزن نمونه و یادداشت روز
- ویرایش خودکار ثبت همان روز (upsert) و اعتبارسنجی (تلفات بیش از تعداد زنده، تاریخ آینده و…)
- مقایسه وزن گله با **استاندارد مرجع رشد نژاد (راس ۳۰۸)** و محاسبه درصد اختلاف
- محاسبه ضریب تبدیل خوراک (FCR) و مقایسه با استاندارد
- نمودارهای تعاملی: وزن در برابر استاندارد، مصرف دان، مصرف آب و تلفات روزانه

### شفافیت هزینه‌ها
- ثبت هزینه در ۱۰ دسته (جوجه، دان، دارو، واکسن، کارگر، انرژی، بستر، حمل، تجهیزات، سایر)
- ثبت خودکار هزینه جوجه در زمان ایجاد دوره
- مدیریت موجودی دان (خرید، مصرف، کفایت روزها) و هشدار اتمام انبار
- محاسبه بهای تمام‌شده هر کیلوگرم وزن زنده، هزینه هر قطعه و نقطه سربه‌سر
- ترکیب هزینه‌ها (نمودار دونات و میله‌ای) و مقایسه با بنچمارک صنعت
- گزارش ماهانه (تقویم شمسی) هزینه و درآمد + خروجی CSV (ثبت روزانه، هزینه‌ها، فروش)

### تصمیم‌یار هوشمند
مشاور فارسی‌زبان که روی داده واقعی همان مزرعه تحلیل عددی ارائه می‌دهد:
- **زمان فروش:** سود فروش امروز در برابر صبر تا سن هدف، ارزش رشد یک روز، توصیه فروش پله‌ای
- **سفارش دان:** مصرف روزانه پیش‌بینی‌شده، موجودی، مقدار سفارش پیشنهادی و هزینه آن
- **تحلیل تلفات:** مقایسه با الگوی مورد انتظار، جهش تلفات، چک‌لیست تشخیص بر اساس علائم (تنفسی، گوارشی، پا، گرما)
- **هزینه و سود:** ترکیب هزینه، حاشیه هر کیلوگرم، پیشنهادهای کاهش هزینه
- **پیش‌بینی پایان دوره:** وزن، دان، FCR، هزینه، درآمد و سود + تحلیل حساسیت به قیمت بازار
- **مقایسه سالن‌ها و برنامه سلامت**
- پشتیبانی اختیاری از مدل زبانی: با تنظیم `OPENAI_API_KEY`، پاسخ‌ها با LLM غنی‌سازی می‌شوند؛ در غیر این صورت موتور تحلیل محلی (آفلاین) پاسخ می‌دهد و داده‌ای به بیرون ارسال نمی‌شود.

### هشدارهای هوشمند خودکار
تلفات بالاتر از انتظار، جهش تلفات، عقب‌ماندگی وزن، FCR بالا، کمبود دان، نسبت غیرعادی آب به دان، دمای خارج از محدوده، نبود وزن‌کشی، حاشیه سود نازک و پنجره فروش — با توصیه اقدام و لینک مستقیم.

## راه‌اندازی

```bash
npm install
npm run dev      # http://localhost:3000
# یا نسخه تولید
npm run build && npm start
```

نیازمندی: Node.js 20+.

داده‌ها در بانک اطلاعاتی SQLite محلی (`data/farm.db`) ذخیره می‌شوند. در اولین اجرا، سه دوره نمونه (دو فعال و یک بسته‌شده) ساخته می‌شود تا همه بخش‌ها قابل بررسی باشند. از صفحه **تنظیمات** می‌توانید داده نمونه را بازنشانی یا همه داده‌ها را پاک کنید.

### متغیرهای محیطی اختیاری

| متغیر | توضیح |
|---|---|
| `OPENAI_API_KEY` | فعال‌سازی پاسخ‌های مبتنی بر مدل زبانی |
| `OPENAI_MODEL` | نام مدل (پیش‌فرض `gpt-4o-mini`) |
| `FARM_DB_PATH` | مسیر دلخواه بانک اطلاعاتی |
| `FARM_TIMEZONE` | منطقه زمانی مبنای تاریخ‌ها (پیش‌فرض `Asia/Tehran`) |

## مبانی محاسبه

- **استاندارد رشد:** نقاط مرجع روزانه نژاد راس ۳۰۸ (وزن و دان تجمعی) با درون‌یابی
- **FCR:** دان مصرفی ÷ (وزن زنده + وزن فروش‌رفته − وزن اولیه جوجه‌ها)
- **بهای تمام‌شده هر کیلو:** مجموع هزینه‌ها ÷ توده زنده
- **پیش‌بینی پایان دوره:** عملکرد نسبی گله (وزن فعلی ÷ استاندارد) اعمال‌شده بر وزن استاندارد سن هدف؛ دان باقی‌مانده بر پایه استاندارد و عملکرد خوراک گله
- **حاشیه سود:** (درآمد − هزینه) ÷ درآمد

> این اعداد برای مقایسه، هشدار و تصمیم‌یاری طراحی شده‌اند و جایگزین نظر دامپزشک یا کارشناس تغذیه نیستند.
